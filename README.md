# Clamshell

A collection of tools for .flac and .mp3 music handling.

- main.py: all-in-one PySide6 app combining both tools
- cover_converter.py: convert cover art from .png to .jpeg
- playlist_organizer.py: organize and create custom playlist folders
- downsampler.py: convert 24-bit+ FLAC albums down to 16-bit (requires ffmpeg on PATH)
